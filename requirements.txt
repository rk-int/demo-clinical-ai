# ------------------------------------------------------------------------------
# 4. Quick Start Commands for Local Execution
# ------------------------------------------------------------------------------
# Step 1: Clone or extract the project directory
#   cd <project-folder>
#
# Step 2: Configure Environment Variables
#   cp .env.example .env
#   (Add your GEMINI_API_KEY in .env if testing live AI inference)
#
# Step 3: Install Dependencies
#   npm install
#
# Step 4: Run Development Server (Frontend + Express Backend on Port 3000)
#   npm run dev
#
# Step 5: Open Browser
#   Navigate to http://localhost:3000
#
# Production Build & Start:
#   npm run build
#   npm start
